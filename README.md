# AluraStore - Análise de Faturamento por Loja

Este projeto consiste em uma análise de dados de vendas de quatro lojas da **AluraStore**, fornecidos em arquivos `.csv`. O objetivo principal é identificar padrões de desempenho, comparar o faturamento entre lojas e avaliar o frete médio por unidade, utilizando ferramentas como **Python**, **Pandas** e **Matplotlib**.

---

## 📊 Objetivo da Análise

- Avaliar o desempenho individual de cada loja.
- Identificar qual loja teve o menor faturamento.
- Visualizar graficamente o frete médio por loja.
- Comparar o percentual de participação no faturamento total.
- Trabalhar com métricas básicas e visualizações para facilitar a tomada de decisão.

---

## 📌 Conclusões Principais

- A **Loja 4** foi a que apresentou **menor faturamento**, mesmo com avaliações similares e frete médio próximo ao das demais.
- O **frete médio** entre as lojas não teve grande variação, portanto, **não foi um fator decisivo** na análise.
- A métrica mais relevante foi o **faturamento total**, obtido através da soma dos valores de venda por loja.
